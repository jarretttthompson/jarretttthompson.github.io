📷 Photo Upload Setup

Run this file locally (double-click to open in your browser). It never sends your token anywhere — all crypto happens in-page.

1 Create a GitHub Personal Access Token

  1. Go to github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Click "Generate new token"
  3. Token name: portfolio-photo-upload
  4. Expiration: 1 year (or custom — you'll need to re-run this setup when it expires)
  5. Repository access: Only select repositories → choose jarretttthompson/thejrummer.art
  6. Permissions → Repository permissions → Contents → Read and write
  7. Leave everything else at the default (No access)
  8. Click "Generate token" and copy it — you won't see it again

2 Encrypt your token

Your token is encrypted with AES-GCM using a key derived from your password (PBKDF2, 200k rounds). The output is safe to commit to a public repo — without the password it's useless.

4 Upload your first photo

On your phone (or desktop), bookmark this URL:

https://thejrummer.art/photo-album.html?upload

When you visit it, an upload panel appears at the top of the photo album. Enter your password, pick a photo, add an optional caption, and tap Upload. Your photo will appear in the album in about 60 seconds (GitHub Pages rebuild time).

Token expired? Come back to this setup file, generate a new PAT, re-encrypt, and paste the new blob into photo-upload.js.
